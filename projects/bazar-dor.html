Overview

About the Project

BazarDor is a daily market price tracking web application designed to help users explore and compare the prices of essential products across different markets in Bangladesh.

It provides price trend insights, category based product browsing, and market wise price comparisons, so people can see what is getting more expensive or cheaper before they go shopping. Product details are protected behind authentication, with email/password, Google and GitHub signin.

The app is built with the Next.js App Router, TypeScript and Tailwind CSS, uses MongoDB for data, and is deployed on Vercel with a fully responsive interface for a smooth experience on all devices.

Challenges Faced

What I Learned & Overcame

01

Authentication & Protected Routes

Setting up Better Auth with email/password plus Google and GitHub OAuth, managing sessions, and restricting product detail pages to signed in users in the Next.js App Router.

02

Modeling Price & Market Data

Designing MongoDB data for products, categories and multiple markets, and calculating daily change, minimum, maximum and average prices correctly.

03

Market wise Price Comparison

Presenting prices from different markets in a way that is easy to read and compare without overwhelming users with too much data.

04

TypeScript & Responsive UI

Keeping data types consistent between the database, server and UI, and building a Tailwind CSS layout that works from small phones to large desktops.
