Overview

About the Project

ShopZen is a fully responsive e-commerce frontend application that I built during my internship at Eutropia IT. The project simulates a real-world online shopping experience with a focus on clean UI, smooth interactions, and mobile-first design principles.

The goal was to deliver a polished, pixel perfect shopping interface that works flawlessly across all device sizes — from mobile phones to large desktop screens.

Working on this project gave me hands on experience with professional web development workflows, team collaboration using Git and GitHub, and the discipline of writing clean, maintainable code for a real client product.

Features

Key Features

✓

Responsive Product Grid

Fully responsive product listing page with CSS Grid and Flexbox that adapts beautifully from mobile to desktop.

✓

Shopping Cart UI

Interactive cart functionality using Vanilla JavaScript and localStorage to persist cart items across page refreshes.

✓

Mobile First Design

Designed with a mobile first approach ensuring the best experience on all screen sizes from 320px to 1440px+.

✓

Smooth Hover Animations

Product cards with smooth CSS transitions on hover — scale, shadow, and color effects for a premium feel.

✓

Navigation & Search UI

Clean navigation bar with category links, search bar, and cart icon with item count badge.

✓

Cross Browser Compatible

Tested and verified across Chrome, Firefox, Edge, and Safari for consistent rendering.

Challenges Faced

What I Learned & Overcame

01

Cart State Without a Framework

Building a functional, persistent shopping cart using only Vanilla JavaScript and localStorage — without React's state management — required careful planning of data structures and event handling.

02

Pixel Perfect Responsive Layouts

Creating consistent, beautiful layouts across all device sizes without a CSS framework like Tailwind required deep understanding of CSS Grid, Flexbox, and media queries.

03

Cross Browser Consistency

Ensuring the UI rendered consistently across different browsers required vendor prefix handling and careful CSS fallbacks for older browser support.
