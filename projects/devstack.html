Overview

About the Project

Dev Stack Builder is a React + TypeScript SPA (Single Page Application) that allows developers to explore various technologies and build their own custom technology stacks interactively. Users can browse technologies by category, view detailed descriptions, and add them to their personalized stack.

This project was built as part of a programming assignment to demonstrate proficiency in React component architecture, TypeScript typing, and Tailwind CSS for rapid, utility first styling.

It's deployed on Netlify with automatic CI/CD from the GitHub repository, showcasing a real world modern development workflow with Vite as the build tool.

Challenges Faced

What I Learned & Overcame

01

TypeScript Interface Design

Designing comprehensive TypeScript interfaces for technology data and component props was challenging but rewarding. Learning to properly type state, events, and component props improved code reliability significantly.

02

Complex State Management

Managing the selected stack state across multiple components — add, remove, and clear operations — required careful thinking about unidirectional data flow in React without over engineering the solution.

03

Intuitive UX for Stack Building

Designing an intuitive user interface where users can easily understand how to browse, select, and manage technologies required multiple iterations of the layout and interaction design.

04

Tailwind CSS Learning Curve

Mastering Tailwind's utility first approach and knowing when to use custom CSS versus Tailwind utilities required practice and developing an intuition for the framework's constraints.
